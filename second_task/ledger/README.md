# ledger

Учёт транзакций с бюджетами по категориям. Консольная программа (HTTP-сервера нет):
при запуске загружает бюджеты, пытается добавить несколько транзакций и печатает список сохранённых.

## Требования

- Go (версия не ниже указанной в `go.mod`), проверить: `go version`

## Запуск

```bash
cd second_task/ledger
go run .
```

Программа читает файл `budgets.json` из **текущей директории** (запускайте из `second_task/ledger`).
Если файла нет, она сообщит об ошибке и завершится.

Формат `budgets.json` (массив бюджетов):

```json
[
  {"Category": "food", "Limit": 5000, "Period": "2026/10"}
]
```
