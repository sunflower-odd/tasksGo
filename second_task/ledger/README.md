# ledger

Учёт транзакций с бюджетами по категориям. Консольная программа (HTTP-сервера нет):
при запуске загружает бюджеты, пытается добавить несколько транзакций и печатает список сохранённых.

## Требования

- Go (версия не ниже указанной в `go.mod`), проверить: `go version`

## Запуск

```bash
cd second_task/ledger
go run .
```

Программа читает файл `budgets.json` из **текущей директории** (запускайте из `second_task/ledger`).
Если файла нет, она сообщит об ошибке и завершится.

Формат `budgets.json` (массив бюджетов):

```json
[
  {"Category": "food", "Limit": 5000, "Period": "2026/10"}
]
```

## Тесты

```bash
cd second_task/ledger
go test ./...        # все тесты
go test -v ./...     # подробный вывод
go vet ./...         # статическая проверка
```

Тесты в `ledger_test.go`: табличные проверки `Validate()` для транзакций и бюджетов
(параллельные, `t.Parallel()`) и сценарий превышения бюджета. Перед каждым тестом,
который меняет данные, вызывается `Reset()`, чтобы тесты не влияли друг на друга.

Перед первым запуском нужна зависимость testify:

```bash
go get github.com/stretchr/testify
```

### Покрытие

```bash
go test ./... -cover -coverprofile=cover.out
go tool cover -html=cover.out -o cover.html   # открыть cover.html в браузере
```

**Покрытие тестами пакета `ledger` ~54%.**
