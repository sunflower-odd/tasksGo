# gateway

Простой HTTP-сервис. 
Эндпоинты: 
* health-check.

| Метод | Путь    | Ответ                   |
|-------|---------|-------------------------|
| GET   | `/ping` | `200 OK`, тело `pong`   |

## Запуск

```bash
cd second_task/gateway
go run .
```

Сервис слушает порт **8080**. Остановка: `Ctrl+C`.

## Проверка

В другом терминале:

```bash
curl -i http://localhost:8080/ping
```

Ожидается `HTTP/1.1 200 OK` и тело `pong`.

Если порт занят, сервис завершится сразу после старта: проверьте, что 8080 свободен
(`lsof -i :8080`).
